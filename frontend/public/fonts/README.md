# Arboria webfonts

Place licensed **Arboria** files here (WOFF2 preferred):

| File | Style |
|------|--------|
| `Arboria-Book.woff2` | Book — body copy (`font-weight: 400`) |
| `Arboria-BlackItalic.woff2` | Black Italic — headings (`font-weight: 900`, `font-style: italic`) |

WOFF fallbacks (`Arboria-Book.woff`, `Arboria-BlackItalic.woff`) are also supported.

Fonts are loaded via `app/styles/arboria.css`. If files are missing, the browser falls back to system UI sans until you add them.
